EXERCÍCIO 1
--------------------------------------------------------------------------------
Programa: Array0.java

a) Quando se cria um array de valores numéricos, com que valor os seus elementos são automaticamente inicializados?
Resposta: 
Quando um array de tipos numéricos é instanciado em Java (na memória Heap), seus elementos são inicializados automaticamente com o valor padrão 0 (zero) para tipos inteiros (byte, short, int, long) ou 0.0 para tipos de ponto flutuante (float, double).

b) Como se faz para saber qual o número de elementos de um array?
Resposta: 
Utiliza-se a propriedade/atributo público embutido .length do array.
Exemplo: dados.length (retorna um número inteiro representando o tamanho total alocado para o array).

EXERCÍCIO 6
--------------------------------------------------------------------------------
Código analisado:
public class Array1 {
    public static void main(String argv[]) {
        int cont;
        int[] dados;
        dados = {1, 2, 3, 4, 5, 6};
        for (cont = 0; cont < dados.length; cont++) {
            System.out.println(dados[cont]);
        }
    }
}

a) Mensagem de erro fornecida pelo compilador:
"Array initializer is not allowed here" (ou "illegal start of expression").

b) O que ela quer dizer?
Resposta:
Em Java, a sintaxe simplificada de inicialização direta por chaves { ... } só é permitida na mesma linha em que a variável do array é declarada (ex: int[] dados = {1, 2, 3, 4, 5, 6};).
Quando a variável de referência é apenas declarada na Stack em uma linha (int[] dados;) e a atribuição de valor é feita posteriormente em outra linha, o bloco {1, 2, 3, 4, 5, 6} solto não possui um tipo inferido pelo compilador.
Portanto, para inicializar o array em uma instrução separada, é obrigatório usar a instanciação explícita na Heap com a palavra-chave 'new' e o tipo do array:
dados = new int[]{1, 2, 3, 4, 5, 6};
